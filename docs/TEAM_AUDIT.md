## Existing journeys

Authentication -> JWT -> database user/active check -> scoped application query. Institution creates DRAFT, edits formData, uploads to protected storage, submits -> synchronous validation. Scrutiny officer inspects documents/OCR/ELA/authority comparisons, updates findings, requests rectification and recommends. Institution revises editable application and resubmits. Regional director records noted decision; final approval/rejection -> DECIDED. PDF export and reviewer actions append audit events. Dashboard and alerts read persisted application state.

No new service, schema migration, database reset, real authority integration, evaluation regeneration, deployment or release tag was performed. Full requirement status is in MASTER_PROMPT_STATUS.md.
