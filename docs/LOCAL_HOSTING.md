# Local hosting - verified 27 October 2026

VeriSense runs as one background FastAPI process serving the built React frontend and API at http://127.0.0.1:8001. Portal: http://127.0.0.1:8001/portal/login. Interactive API documentation: http://127.0.0.1:8001/docs. The listener is bound to this computer's loopback interface.

Portable Node 22.23.4, uv and Python 3.11.18 were downloaded into ignored `.local-tools/`. Locked frontend/backend dependencies are installed in `frontend/node_modules` and `backend/.venv`. No system-wide installation is required. Runtime files, credentials and logs are in ignored `.local-run/`; local databases and uploaded files retain their existing ignored locations.

Start again from the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

Stop the managed server process tree while preserving data:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop-local.ps1
```

The execution-policy option applies only to the launched PowerShell process. The start script uses the installed backend environment and existing frontend build; it does not reinstall dependencies. Synthetic data is seeded only when the database has no users. The first seed completed successfully; later starts preserve the database. A random JWT secret persists in `.local-run/.jwt-secret`.

Demo login: `officer.wro` / `Demo@2026`. Other demo accounts are in README.md. All authority integrations remain simulated. This is local demonstration hosting, not production deployment.
