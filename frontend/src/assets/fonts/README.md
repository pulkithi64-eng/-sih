# Inter font

Inter Latin variable font, normal style, weights 400-700. Downloaded 27 October 2026 from the official Google Fonts stylesheet for `Inter:wght@400..700`, hosted by fonts.gstatic.com. The matching font-face metadata and Latin Unicode coverage are in src/index.css.

Original project: https://github.com/rsms/inter. License: SIL Open Font License 1.1, preserved in OFL.txt. No font request leaves the deployment at runtime. Vite fingerprints the WOFF2 asset for cache invalidation.
